# RankUoG

GPA ranking and leaderboard platform for University of Guyana students.

## Docs

Full documentation: [Notion — TradeGuyz Software → Rank UoG](https://www.notion.so/331ef664edfe8098af30ee8c4f4bc3ee)

## Stack

- **Frontend:** React 19 + TypeScript + Vite + Tailwind CSS v4
- **Database:** Supabase (PostgreSQL)

## Development

```bash
cd frontend
npm install
npm run dev
```
